# 🤖 Day 9 – Prediction Project 
🚀 AI & ML Internship @ Codomax Digital Solutions  

## 📌 Overview  
This project is part of Day 9 – Prediction in my AI & Machine Learning Internship. It demonstrates how to build, save, load, and use a Machine Learning model to predict student scores based on study hours.

## 🎯 Objective  
- Build a Machine Learning model using Linear Regression  
- Predict scores based on study hours  
- Evaluate model performance  
- Visualize results using graphs  
- Save and reuse the trained model  

## 🧠 Concepts Covered  
- Supervised Learning  
- Linear Regression  
- Model Training & Prediction  
- Model Evaluation (R² Score)  
- Data Visualization (Matplotlib)  
- Model Saving & Loading (Joblib)  

## 📂 Project Structure  
```
Day-09-Prediction/
│── prediction_full.py
│── requirements.txt
│── README.md

```

## 🧪 Implementation Details  
- Created dataset of study hours vs scores  
- Trained Linear Regression model  
- Saved model using Joblib  
- Loaded model for reuse  
- Predicted scores for user input  
- Evaluated model using R² Score  
- Visualized results using graph  

## ▶️ How to Run  
```bash
pip install -r requirements.txt
python prediction_full.py
```
