# 🤖 Day 10 – Model Evaluation  
🚀 AI & ML Internship @ Codomax Digital Solutions  

## 📌 Overview  
This project focuses on evaluating a Machine Learning model using performance metrics like MAE, MSE, and R² Score to measure how well the model predicts results.

## 🎯 Objective  
- Evaluate model performance  
- Understand error metrics  
- Compare actual vs predicted values  
- Measure accuracy of the model  

## 🧠 Concepts Covered  
- Mean Absolute Error (MAE)  
- Mean Squared Error (MSE)  
- Root Mean Squared Error (RMSE)  
- R² Score  

## 📂 Project Structure  
```
Day-10-Model-Evaluation/
│── model_evaluation.py
│── requirements.txt
│── README.md
```

## 🧪 Implementation Details  
- Created dataset (study hours vs scores)  
- Split data into training and testing sets  
- Trained Linear Regression model  
- Predicted test values  
- Evaluated model using MAE, MSE, RMSE, R²  

## ▶️ How to Run  
```bash
pip install -r requirements.txt
python model_evaluation.py
```
