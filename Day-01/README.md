
# AI & ML Internship – Day 1  
##  Environment Setup Verification  

> Beginning my journey into Artificial Intelligence & Machine Learning

---

## Objective  

The goal of Day 1 is to successfully set up and validate a complete development environment required for AI & ML tasks. This includes installing essential tools and ensuring everything works correctly by running a Python program.

---

## Program Name  

Environment Setup Verification

This Python-based tool checks whether the system is properly configured and ready for AI, Machine Learning, and Data Science development.

---

##  Features  

- Displays internship and program details  
- Shows system information (OS & Architecture)  
- Displays Python version and path  
- Checks availability of essential tools:  
  - Python  
  - VS Code  
  - Git  
  - Jupyter Notebook  
- Provides a final confirmation message with successful setup status  

---

##  Technologies Used  

- Python 3  
- Visual Studio Code  
- Git & GitHub  
- Jupyter Notebook
