## 🧠 Concepts Covered

### ✅ Supervised Learning

A type of Machine Learning where the model is trained using **labeled data** (input → output mapping).

---

### ✅ Train-Test Split

* **Training Data (80%)** → Used to train the model
* **Testing Data (20%)** → Used to evaluate performance

---

### ✅ Linear Regression

A simple and widely used algorithm to find the **relationship between variables**.

**Formula:**

```
y = mx + c
```

Where:

* *m* = slope
* *c* = intercept

---

## ⚙️ Implementation Steps

* 🔹 Import required libraries (*Pandas, Scikit-learn*)
* 🔹 Create or load the dataset
* 🔹 Define input features (**X**) and target variable (**y**)
* 🔹 Split dataset into training and testing sets
* 🔹 Initialize Linear Regression model
* 🔹 Train the model using training data
* 🔹 Make predictions on test data
* 🔹 Compare actual vs predicted values
* 🔹 Analyze model using slope & intercept
