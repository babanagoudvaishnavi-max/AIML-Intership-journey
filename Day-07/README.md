 Concepts Covered

✅ Supervised Learning  
A type of learning where the model is trained using labeled data (input → output).

✅ Train-Test Split  
- Training Data (80%) → Used to train the model  
- Testing Data (20%) → Used to evaluate the model  

 ✅ Linear Regression  
A simple algorithm used to find the relationship between variables.  

 Formula:  
y = mx + c
