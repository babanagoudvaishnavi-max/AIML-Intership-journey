# 🤖 Day 11 – Prediction App  
🚀 AI & ML Internship @ Codomax Digital Solutions  

## 📌 Overview  
This project builds a simple Prediction App where users can input study hours and get predicted scores using a trained Machine Learning model.

## 🎯 Objective  
- Take user input  
- Use trained model for prediction  
- Build a simple interactive program  
- Display predicted output  

## 🧠 Concepts Covered  
- Model Deployment (Basic)  
- User Input Handling  
- Prediction using trained model  
- Joblib (Model Saving & Loading)  

## 📂 Project Structure  
```
Day-11-Prediction-App/
│── prediction_app.py
│── requirements.txt
│── README.md
```

## 🧪 Implementation Details  
- Trained Linear Regression model  
- Saved model using joblib  
- Loaded model in app  
- Took user input (study hours)  
- Predicted student score  

## ▶️ How to Run  
```bash
pip install -r requirements.txt
python prediction_app.py
```

## 📊 Sample Output  
```
Enter study hours: 5  
Predicted Score: 64.50  
```
