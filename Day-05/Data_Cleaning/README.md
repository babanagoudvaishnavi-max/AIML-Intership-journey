# Day 5 – Data Cleaning Using Pandas

## Objective
The objective of this project is to clean a dataset using the Pandas library by handling missing values, removing duplicate records, and generating a cleaned dataset.

## Tools Used
- Python
- Pandas
- Jupyter Notebook

## Files Included
- sample_dataset.csv
- cleaned_dataset.csv
- day5_data_cleaning.py
- day5_data_cleaning.ipynb
- README.md

## Steps Performed
1. Imported the Pandas library.
2. Loaded the dataset.
3. Displayed the dataset and dataset information.
4. Checked for missing values.
5. Filled missing values using the mean and "Unknown".
6. Removed duplicate rows.
7. Displayed the statistical summary.
8. Saved the cleaned dataset.

## Output
The cleaned dataset is saved as **cleaned_dataset.csv**.
