## 📊 Dataset Details

The dataset includes the following features:

* Study_Hours
* Sleep_Hours
* Participation (Low / Medium / High)
* Previous_Grade
* Internet_Usage
* Health_Condition (Poor / Average / Good)
* **Attendance_Percentage (Target Variable)**
